# Do-do2 To-Do List Application

A simple text-based to-do list application built in Python. This program allows users to create, view, edit, and save tasks in a CSV file.

## Features

- Add tasks to your to-do list
- View existing tasks
- Edit task names, statuses, or priority levels
- Mark tasks as completed
- Delete tasks or all tasks
- Save tasks to a CSV file and load them later
